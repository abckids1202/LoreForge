# Roadmap

- Lore entry CRUD
- Markdown editor with preview
- Tags and filters
- Entry detail pages
- Search across title, summary, content, status, visibility, and importance

## Phase 3: Structured Profiles

- Character profiles
- Faction profiles
- Location profiles
- Event profiles
- Artifact profiles

## Phase 4: Relationships

- Relationship CRUD
- Incoming/outgoing entry panels
- Duplicate prevention
- Strength, visibility, directionality, and status controls

## Phase 5: Timeline and Graph

- Timeline query and UI
- Event participant model
- Interactive graph view
- Graph filters and focus mode

## Phase 6: Canon and Exports

- Contradiction workflow
- Notes
- Markdown export
- JSON export
- Export configuration

## Phase 7: AI Assistance

- Provider abstraction
- Naming assistant
- Lore expansion suggestions
- Relationship suggestions
- Contradiction detector
- Theme analyzer
